# AION Unified API

OpenAPI specification for the APIs shared between AION and Vision Bank (reference beneficiary,
transfer, bill payment, MOI refund, user access profile, audit logs, SME validations).

## View the latest version (no import needed)

**[Open the latest specification](https://editor.swagger.io/?url=https://raw.githubusercontent.com/touqir-asghar/vb-api-docs/main/aion-unified-api.yaml)**

The link always shows the current version from this repository.

Source file: [`aion-unified-api.yaml`](aion-unified-api.yaml)

## Updating

1. Create a branch, edit `aion-unified-api.yaml`, and bump `info.version`.
2. Open a pull request into `main` for review.
3. After merge, tag the version (e.g. `v1.0.1`). The link above shows the new version automatically.
